# Group by

_Group a table by column values and aggregate each group. These methods are available on `pykx.Table` and `pykx.KeyedTable` objects._

The aggregations `sum`, `prod`, `min`, `max`, `mean`, `median`, `count`, `std`, `sem`, `skew`, `kurt`, `idxmax`, `idxmin`, `any` and `all` can be called on the result of `groupby`. They are described on the [metadata and aggregations](metadata.md) page.
