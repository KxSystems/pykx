# Loading KDB-X Modules

_This page documents how to load KDB-X q modules into Python with `kx.use`, the `QModule` objects returned, and the `SearchPath` used to locate them._

For a guided introduction with examples of each published module, see [Load KDB-X modules](../user-guide/advanced/modules.md). For the list of available modules, see the [KDB-X module index](https://code.kx.com/kdb-x/modules/module-index.html).
